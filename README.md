# Aplicativo-informativo-sobre-o-filme-De-volta-para-o-futuro-
Aplicativo desenvolvido em Programação Orientada a Objetos para apresentar informações sobre o filme De Volta para o Futuro, incluindo enredo, elenco, dados técnicos, curiosidades e links oficiais. Os conteúdos são carregados a partir de arquivos JSON e apresentados por meio de uma interface interativa
