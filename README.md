## Tema do aplicativo

Aplicativo desenvolvido com o objetivo de apresentar informações sobre o filme *De Volta para o Futuro*, utilizando conceitos de Programação Orientada a Objetos.

O aplicativo apresenta informações como enredo, elenco, dados técnicos, curiosidades e links para sites oficiais relacionados à obra e aos artistas.

Os conteúdos apresentados no aplicativo são carregados a partir de arquivos JSON e utilizados para instanciar objetos e listas, evitando o uso de textos estáticos diretamente na aplicação.
