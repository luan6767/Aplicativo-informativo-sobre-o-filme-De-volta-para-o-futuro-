## Tema do aplicativo

Aplicativo informativo sobre o filme *De Volta para o Futuro*, desenvolvido utilizando conceitos de Programação Orientada a Objetos.

O aplicativo apresenta informações sobre o enredo, elenco, dados técnicos, curiosidades e links oficiais relacionados à obra e aos artistas.

Os conteúdos são carregados a partir de arquivos JSON e utilizados para instanciar objetos e listas, evitando o uso de informações estáticas diretamente na aplicação.
